# FIRAS TV — Android 2.1.2

مشروع Android الأصلي لتطبيق FIRAS TV. يجري التطوير على الفرع `restore-source-2.1.3` مع إبقاء فرع `main` منفصلاً.

## ما يتضمنه هذا الإصدار
- واجهة عربية RTL بتصميم أسود وأحمر.
- تخطيط أفقي واسع للهواتف والأجهزة اللوحية: مشغل بجانب قائمة القنوات.
- مشغل فيديو مع وضع ملء الشاشة ودعم HLS عبر hls.js.
- أيقونة Android خاصة بالتطبيق.
- إضافة القنوات التسع الموجودة في `channels.json` تلقائياً عند أول تشغيل، دون استبدال قنوات المستخدم الموجودة.
- نسخة احتياطية تشمل القنوات والتصنيفات والمفضلة وسجل المشاهدة والإعدادات.

## تنزيل APK
1. افتح [سجل بناء FIRAS TV على GitHub Actions](https://github.com/trekforbeer-lang/FIRAS-TV-Android/actions/workflows/android.yml).
2. اختر أحدث تشغيل على الفرع `restore-source-2.1.3` وانتظر ظهور علامة نجاح خضراء.
3. افتح التشغيل، ثم انزل إلى **Artifacts**.
4. نزّل الملف `FIRAS-TV-APK` وفك ضغطه.
5. ثبّت `app-debug.apk` على هاتف Android.

## معلومات البناء
- Java 17
- Gradle 8.7
- Android Gradle Plugin 8.6.1
- Compile SDK 35 / Target SDK 35
- Application ID: `com.firas.tv`
- Version: `2.1.2` (versionCode 5)
- ناتج البناء الحالي Debug APK للتجربة، وليس إصداراً Release موقعاً للنشر.

## الحفاظ على البيانات
لا تستبدل `channels.json` أو تحذف قنوات من بيانات المستخدم. عند أول تشغيل فقط، تُدمج قنوات البداية مع البيانات الحالية دون حذفها. يمكن إنشاء نسخة احتياطية كاملة من لوحة الإدارة.

## ملاحظات الاختبار
نجاح بناء APK لا يعني أن كل رابط بث يعمل دائماً؛ صلاحية البث تعتمد على خادم القناة وتوفره وقيوده. يلزم اختبار التشغيل على جهاز Android فعلي قبل اعتبار المشغل مختبراً بالكامل.
