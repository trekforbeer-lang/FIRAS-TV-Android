# FIRAS TV — إصدار Cloud Build 2.1.3 (ملفات التطبيق 2.1.1)

هذه حزمة مصدر Android مع إعداد GitHub Actions للبناء السحابي. لم يتم إنتاج APK محلياً في بيئة التحرير الحالية؛ البناء النهائي يجب أن يتم في GitHub Actions أو Android Studio.

## بناء APK عبر GitHub
1. ارفع محتويات هذا الأرشيف إلى جذر المستودع GitHub، وليس داخل مجلد فرعي إضافي.
2. افتح تبويب Actions.
3. اختر Build FIRAS TV APK ثم Run workflow (أو ادفع commit إلى main/master).
4. بعد نجاح المهمة، افتح تفاصيل التشغيل ثم Artifacts وحمّل `FIRAS-TV-debug-APK-*`.

## معلومات البناء
- Java: 17
- Gradle: 8.9 (يُدار من GitHub Actions)
- Android Gradle Plugin: 8.6.1
- Compile SDK: 35
- APK الناتج: Debug غير موقّع للنشر الرسمي

## المحافظة على المصدر
ملف `app/src/main/assets/channels.json` محفوظ دون تعديل عن المصدر المرفق. تجنّب استبداله أو حذف القنوات ما لم تُراجع روابطها أولاً.

## ملاحظات الاختبار
- هذه الحزمة تحتوي على مصدر المشروع فقط، وليست APK.
- لم يتم إجراء build حقيقي داخل هذه البيئة لعدم توفر Gradle/Android SDK.
- روابط البث تحتاج اختباراً عملياً؛ وجودها في القائمة لا يضمن استمرارها أو صلاحية استخدامها.
- استخدم مصادر بث لديك حق الوصول إليها.
